# Index Text Language (ITL) — Numbered v1.0.0

ITL is a text-first programming language. In ITL Numbered v1.0.0,
everything is an indexed text — every character, word, and line has a number.

Extension: `.itl`
Entry point: `itl-lang("start");`

Built for simple, direct text processing where indexing is the core, not an afterthought.
