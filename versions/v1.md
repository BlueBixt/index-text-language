## What is ITL Numbered v1.0.0?

ITL Numbered v1.0.0 is the first stable release of Index Text Language.

**Core Idea:** In most languages, text indexing is an extra feature (text[0]).
In ITL, indexing IS the language. Text is not a string — it's a numbered collection from the start.

**Features in v1.0.0:**
- File format: `.itl`
- Required header: `itl-lang("start");` and footer `itl-lang("end");`
- Native `print` for indexed output
- Numbered access to text data
- Minimal src/ with lexer, parser, interpreter

**Philosophy:**
If you work with text, you shouldn't have to fight the language to get to character 5.
In ITL, you just do.

**Example:**
```itl
itl-lang("start");
print "This is ITL Numbered v1.0.0";
print "Every character has a number";
itl-lang("end");
